# ECT policies (read-only copies)

The official versions of ECT's policies, standards and supporting documents are pages in the Confluence space **Empire City Taxi Governance** (ECTG). That site is private, so a read-only copy of each **approved** document is kept here. If a copy here differs from Confluence, Confluence prevails ([STD-01](STD-01-policy-management-standard.md), section 11).

The master list of every document, approved or not, is the Policy Register (Confluence page, with a data copy in [`data-platform/dbt/seeds/governance/policy_register.csv`](../../data-platform/dbt/seeds/governance/policy_register.csv)).
